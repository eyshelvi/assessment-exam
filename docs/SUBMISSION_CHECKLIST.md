# Submission checklist

Before submitting, ensure your repository contains:

- [/] Working implementation of assignment and combined filtering.
- [/] Automated tests for feature behavior and validation/error cases.
- [/] Create `docs/IMPLEMENTATION_NOTES.md` from `docs/IMPLEMENTATION_NOTES_TEMPLATE.md` — assumptions, design decisions, changes, test command/results, and known limitations.
- [/] Create `docs/QA_REPORT.md` from `docs/QA_REPORT_TEMPLATE.md` — exploratory coverage, defects/risks, severity/priority, reproduction steps, expected vs actual behavior, and disposition.
- [/] Create `docs/AI_USE_DISCLOSURE.md` from `docs/AI_USE_DISCLOSURE_TEMPLATE.md` — tools used, material use, and how generated output was verified; write `No AI tools used` if applicable.
- [ ] A viewable link to a **5–10 minute screen recording** that demonstrates the completed work and explains implementation choices, tests/QA performed, and known limitations/risks.
- [/] A clean README setup path that an evaluator can follow.

Submit a repository link and identify the commit/branch evaluated. Do not submit `.venv`, secrets, or build artifacts.
